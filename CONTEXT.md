# Maplibre Station Map

An React web app that displays hardcoded Stations on a MapLibre map and draws vehicle Routes between pairs of Stations.

## Language

**Station**:
A named location at fixed, hardcoded coordinates, displayed as a marker on the map.
_Avoid_: Marker, pin, waypoint, POI

**Route**:
The road-following line between two Stations, computed for vehicle travel via a routing service.
_Avoid_: Path, line, connection
